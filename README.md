# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/your-repository.git
```

Go to project directory

```bash
cd your-repository
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
